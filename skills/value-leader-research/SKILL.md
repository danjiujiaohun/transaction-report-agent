# 龙头价值股调研（Value Leader Research）

用**价值投资**思路与原则，对**行业龙头 / 大市值盈利企业**做结构化深度调研。

**交付形态（默认）：** 每只股票一个独立文件夹，三者都要有：① 九大部分**加厚分册**；② **总览**（关键指标表 + 图 + 各章浓缩表 + 目录）；③ 一份**单独的投研报告**（表图为主、详略中等）。另附 `data/` 中间文件。禁止为凑篇幅臆造数据。

本 skill 规定「研究什么、按什么顺序、如何下结论、如何落盘」；取数优先复用本仓库的 `a-stock-*` skills。分册扩展细则见 `[reference.md](reference.md)`。

## 适用与不适用（硬边界）

### 适用（满足大部分即可）

- 行业龙头或细分绝对龙头（份额、定价权、品牌或成本位居前列）
- 大市值或准大市值；主业清晰、连续盈利（近两年以盈利为主，非概念故事）
- 用户明确要用价值投资 / 基本面 / 护城河 / 估值框架来看

### 不适用（命中任一条应拒绝或改用其他框架，并明确告知用户）

- **题材股 / 纯概念炒作**（主题叙事主导、基本面无法支撑）
- **小市值股**（流动性差、治理与信息披露波动大，价值框架易失真）
- **亏损股 / 长期微利靠非经常性损益**（无稳定自由现金流叙事）→ 高成长未盈利或高 PE 创新公司改用 `[growth-tech-research](../growth-tech-research/SKILL.md)`
- **半导体 / 创新药 / 互联网软件等成长叙事主导、且用户要空间与成长估值** → `[growth-tech-research](../growth-tech-research/SKILL.md)`（不要用本框架的 PB-ROE 硬套）
- **成熟主业 + 颠覆高方差**（平台巨头、品牌消费、潮玩 IP 等；如腾讯/阿里、珀莱雅/巨子生物、泡泡玛特）→ `[platform-leader-research](../platform-leader-research/SKILL.md)`（分板块 + 颠覆专章 + SOTP，不要用本框架硬套）
- **纯短线、打板、情绪博弈**需求（应改走 `a-stock-pulse` 等交易向 skill）

若用户坚持分析不适用标的：先说明本 skill 边界，再问是否改用 `growth-tech-research`、`platform-leader-research`、「景气/主题」或「短线」框架；**不要假装按价值龙头流程硬套**。

## 核心原则（价值投资）

1. **先生意，后股价**：先弄清赚不赚钱、如何赚钱、现金是否真实、近 1–2 年结构有无质变，再谈竞争、成长与贵贱。
2. **护城河要举证，不贴标签**：竞争格局须看**行业集中度**与**本公司市场份额**；护城河分析须结合**波特五力**，并用**毛利率 / 净利率 / ROE 相对同业**的定量结果交叉验证。禁止只写「护城河深厚」。
3. **成长性必须显式预测**：价值分析不能只有静态财报；须对**行业成长性**与**公司成长性**给出未来几年的营业收入、净利润增速判断（可分情景），再进入估值。禁止把一季高增速直接外推成永续。
4. **估值看相对与历史**：至少同时看 (a) 自身历史分位 (b) 同业相对 (c) 一致预期下的前向估值 (d) **PB-ROE（过去 5 年平均 ROE / 现在的 PB）**；单一 PE 口号不够。PB-ROE 用于平滑短期利润波动，与 PE 对照；PEG 等须与 Step 5 的增长假设一致。
5. **变化比静态更重要**：近 1–2 年基本面与市场定价框架的**转折点**，往往比最新一季数字更关键；市场看法要用叙事阶段与预期差写清。
6. **涨跌要归因，不预测点位**：量化窗口与回撤，主因排序，区分公司特有与板块贝塔；**近端急跌必须落到可指名事件**（日期+主体+内容），禁止只用「情绪/预期差/板块β」交差。不做涨跌保证与目标价。
7. **弱化交易噪声，不弱化定价叙事**：降权的是**龙虎榜、热点概念标签、纯技术形态**。下列内容**不是噪声**，必须写入护城河/市场看法/涨跌归因：大客户切换或自研、多供落地、份额流失担忧、回购落地与否、监管/税改、行业供需与定价框架切换的主流媒体共识。
8. **结论可证伪**：每份报告给出可跟踪信号（何种数据出现则强化/削弱原判断）。
9. **财务可缓存，催化必须保鲜**：用户允许复用旧财报/估值时，**Step 7–8 仍须重新检索近 7–14 天新闻与「下跌原因」公开归因**；报告注明「财务时点」与「催化检索时点」可不同。



## 研究流程（必须按序）

```text
资格预检 → 取数 → 基本面 → 1–2年变化 → 竞争与护城河
→ 成长性预测（行业+公司，营收/净利）→ 估值
→ 市场看法变化 → 近期涨跌归因 → 综合结论与跟踪清单
```



### Step 0 — 资格预检

确认代码、公司名、行业、市值量级、近两年是否持续盈利。若不适用，停止本流程。

#### 1.1 缓存与催化保鲜（硬规则）

| 数据类型 | 可否复用旧抓取 | 说明 |
|----------|----------------|------|
| 三表、估值历史、一致预期快照 | 可（用户同意时） | 注明原抓取日 |
| 现价/市值快照 | 建议刷新；可复用须注明时点 | — |
| **近端新闻、客户/供应链公告、公开「下跌原因」归因** | **不可因「复用财务缓存」而跳过** | 写 Step 7–8 前必做 |

**催化检索最低动作（写 Step 7/8 前）：**

1. 拉取个股近 **7–14 天**新闻（`a-stock-macro` 新闻端点优先）。  
2. **Web 检索**至少两条：`{公司名} 下跌/大跌 原因`、`{公司名} 股价`（近一周）；必要时再搜大客户/行业关键词。  
3. 扫客户侧与供应链：自研电池、二供中标、切换供应商、份额数据、监管处罚等——**不限于本公司公告**。  
4. 将「媒体共识主因」与「本公司财报事实」分开记录；二者冲突时在报告中显式说明。

### Step 2 — 基本面（当下画像）

目标：在谈竞争与估值之前，先看清**这门生意现在如何赚钱、现金是否真实、资产负债是否健康**。按下列框架写，勿只堆指标名。

#### 2.1 生意模式（先于数字）

用一段话回答：

- 公司靠什么收费（产品 / 制造差价 / 品牌溢价 / 服务 / 平台等）？
- 成本结构大致怎样（原材料、制造、研发、销售费用孰重）？
- 客户是谁、订单是否偏大客户招标？

没有模式画像，不得直接跳到增速结论。

#### 2.2 收入与利润结构（分部是硬表，合并三表不能代替）

先回答：按**年报口径的经营分部 / 分产品 / 分地区**，各块收入、利润（或毛利）及增速是多少、增量来自哪一块。是否过度依赖单一客户或单一地区。

**强制：分部表**（至少最新完整会计年度；有中报则再加最新一期）

| 分部（用年报自己的名称） | 收入 | 同比 | 利润或毛利（注明：分部利润 / 利润总额 / 毛利） | 同比 | 占合计 |

纪律：

1. 口径以年报「主营业务分行业 / 分产品 / 分地区」或附注「经营分部」为准，不要自行发明板块名。
2. **禁止用装机容量、销量、门店数、产能结构代替收入和利润。** 那些可以另表，但不能充当本小节的收入结构。
3. 综合能源 / 发电类：收入侧按年报已披露的「电力 / 热力 / 其他」等；利润侧若经营评述另有煤电、气电、水电、风电、光伏的利润总额，必须并表。非电业务（供热、电解铝、煤炭等）年报若未单列分部，须用子公司或经营评述里**可核实**的数字单列，并标明「非分部口径」。
4. **sina 三表、baostock 没有分部。** 数字来自年报/中报经营评述或附注、F10 主营构成、卖方纪要摘录。取不到必须写「未取得」+ 缺哪张表，禁止静默跳过。
5. 然后再给近 **4–8 个报告期**的**合并**关键行：营收、归母净利、毛利率、净利率、EPS、增速。合并表不能替代分部表。
6. 对于数据异常（偏高/偏低、某一分部利润占比突然抬升）的项要重点表述。

#### 2.3 盈利能力与 ROE 自拆（杜邦）

对本公司做时间序列（同业对比主放 Step 4.3）：

- 毛利率、净利率、ROE 水平与趋势
- **杜邦拆解**：ROE ≈ 净利率 × 资产周转 × 权益乘数——高 ROE 若主要来自杠杆，须明示，不得直接等同护城河
- 口径：优先同时列示**归母净利**与**扣非归母**（若可得）；注明是否含大额联营/投资收益

#### 2.4 现金流与自由现金流

- 经营现金流 vs 净利润：是否背离、连续几期
- 投资现金流 / 资本开支强度（扩张性 vs 维持性，能区分则区分）
- **自由现金流（FCF）意识**：粗算可用「经营现金流 − 购建固定资产等资本开支」；讨论分红、回购、再投资是否吃得消
- 价值投资更看重「利润能否变成可分配/可再投资的现金」

#### 2.5 资产负债表与营运资本

- 货币资金、有息负债、**净现金/净负债**、短长期债务结构；资产负债率；利息压力（若明显）
- 营运资本怎么读（须解释含义，不单列科目）：
  - **存货**升：备货还是滞销风险？
  - **应收**升：回款变差还是收入确认节奏？
  - **合同负债/预收**变：需求景气还是定价/交付变化？
  - **应付**变：对上游账期、供应链地位

#### 2.6 盈利质量与股东回报（现状）

- 非经常性损益：政府补助、资产处置、投资收益等是否抬高利润
- 分红率、近期是否回购、股息率（若有）——资本配置的**现状**；政策**变化**写入 Step 3

#### 2.7 输出要求

- 必有关键财务表 + 「强项」「隐患」各 ≥1 条
- 用 2–4 句小结：质量如何、现金转化如何、杠杆是否舒适
- **边界**：不做未来增速预测（→ Step 5）；不做同业护城河定级（→ Step 4）

### Step 3 — 近 1–2 年基本面重大变化（必做）

核心问题（必须直接回答）：

> 过去 1–2 年，公司的**赚钱方式、竞争地位、资本配置**，哪一项发生了不可逆（或难逆）的变化？若几乎没有，明确写「未见重大结构变化」。

本步写**已发生的变化**；未来如何增长留给 Step 5；份额与五力的展开留给 Step 4（此处只记「份额升/降」等事实）。

#### 3.1 转折时间线（强制）

列出 **3–8 个**关键转折（按时间排序），每条尽量含：

`时间 | 事件（财报/公告/战略/行业） | 财务印证（增速、利润率、CapEx、存货等） | 周期波动还是结构变化`

禁止把 Step 2 的静态表换个说法重贴一遍而不标时间拐点。

#### 3.2 周期波动 vs 结构变化（必做判断）

对每个重要变化标注类型：

- **周期**：景气复苏/回落、价格波动带来的利润起伏，生意模式未变
- **结构**：产品代际、成本曲线、份额台阶、出海、一体化、客户结构等导致赚钱方式改变

价值投资更关注结构变化；把周期当质变会高估或低估持续性。

#### 3.3 检查清单（有则写，无则写「未见」）

- 收入/净利增速拐点（加速或失速）、毛利率与净利率趋势
- 产品/技术代际、产能与资本开支节奏
- 客户结构、出海、新业务占比
- 存货、应收账款、合同负债等营运资本趋势变化及其含义
- 竞争加剧或份额变化的财务痕迹（价格、周转、费用率）——细节对手分析见 Step 4
- **管理层与战略切换**：扩产、出海、一体化、并购、新业务是否已反映在 CapEx 与收入
- **盈利质量迁移**：扣非与归母差距、一次性损益、会计政策、商誉/减值前后对比
- **资本配置变化**：分红与回购力度、再投资 vs 返还股东、并购；扩张是否损害资本回报效率
- 治理与股本事件：股权激励、增发、质押、重大诉讼等

#### 3.4 与市场预期的关系（衔接后文）

简要判断：上述变化里，哪些**已被股价/一致预期充分反映**，哪些仍可能是增量信息（为 Step 7 市场看法、Step 8 涨跌归因铺垫）。无需展开估值。

#### 3.5 输出要求

- 先给时间线，再给「结构变化结论」一段话
- 「未见重大变化」是合法结论，但须说明依据（增速、利润率、战略、资本配置均平稳）

### Step 4 — 竞争格局与护城河（必做深化）

本章是价值投资的核心方法论之一，分三块写，**禁止混为一谈**：先格局（集中度与份额）→ 再波特五力（结构力量）→ 再财务定量（利润率/ROE 同业比较）。结论要能回答：公司凭什么赚到超额回报、这种回报能维持多久。

#### 4.1 竞争格局：行业集中度 + 市场份额

**必须回答：**

1. **行业集中度如何？** 尽量给出 CR3 / CR5（或可获得的 CR10、头部市占合计）；注明口径（全球/国内、出货量/装机/收入）与年份。数据可来自研报、行业协会、公司公告；找不到精确数时给出合理区间并标明「估算」。
2. **本公司市场份额有多少？** 近 1–3 年份额是升、稳还是降？与主要对手的差距。
3. **集中度如何影响竞争形态？**
  - **集中度高（寡头）**：进入壁垒通常更高，龙头更易形成定价纪律与规模优势；但头部之间的**份额争夺仍可能非常激烈**（价格、技术、大客户招标）。须区分「对潜在进入者的屏障」与「现有巨头之间的肉搏」。  
  - **集中度低（分散）**：同质化价格战、份额碎片化更常见，单家超额利润更难持续——对「价值龙头」叙事要更苛刻。
4. **主要对手清单**：2–5 家，各写定位（一体化 / 二线 / 海外 / 垂直客户自研等）与差异化。
5. **供需叙事**：行业处于短缺、均衡还是过剩（与产能周期挂钩，供 Step 5 使用）。

输出建议用一小表：`对手 | 份额(估) | 定位 | 相对本公司的威胁点`。

#### 4.2 护城河：波特五力分析框架（必做）

用波特五力把「结构吸引力」与「本公司相对位置」写清楚。每一力判断 **强 / 中 / 弱**，并给证据（事实、合同结构、财务痕迹或研报共识），最后归纳对本公司护城河是加固还是削弱。


| 五力             | 分析要点（举例）                     | 护城河含义                   |
| -------------- | ---------------------------- | ----------------------- |
| **现有竞争者的竞争强度** | 对手数量与实力、份额战/价格战频率、差异化程度、退出壁垒 | 强度高会压缩利润率与 ROE 持续性      |
| **潜在进入者的威胁**   | 资本开支门槛、认证/专利/渠道、政策牌照、学习曲线    | 威胁低 → 壁垒高；威胁高 → 超额利润难持久 |
| **替代品的威胁**     | 技术路线替代、其他材料/工艺/商业模式、客户自研自制   | 替代强则长期成长与估值天花板下移        |
| **供应商的议价能力**   | 关键原料是否垄断、可否多供、一体化程度、成本转嫁能力   | 供应商强则毛利率波动大             |
| **购买者的议价能力**   | 客户集中度、大客户招标、双供/多供策略、产品标准化程度  | 买方强则 ASP 与净利率承压         |


写完五力后，用 3–6 条归纳**护城河来源**（规模成本、认证切换成本、技术迭代、品牌、牌照、网络效应等），每条对应五力中的哪一环；并单列 **护城河变薄路径**（多供、价格战、技术切换、政策、客户自研等）。

#### 4.3 护城河的定量验证：毛利率、净利率、ROE（必做，须同业比较）

财务结果是护城河是否「兑现」的试金石。一般而言：**毛利率、净利率、ROE 相对同业越高、且能在周期中相对更稳，往往说明护城河越宽**（定价权、成本优势或周转/杠杆结构更优）。须做同业比较，禁止只报本公司绝对值。

**必做指标（至少近 3 个完整会计年度 + 最新报告期）：**


| 指标      | 看什么                                   |
| ------- | ------------------------------------- |
| **毛利率** | 产品/成本优势；与同业对比；趋势升/降                   |
| **净利率** | 费用与非经常性损益后的最终盈利能力；是否虚高                |
| **ROE** | 股东回报综合结果；可拆杜邦（净利率 × 周转 × 权益乘数）看优势来自何处 |


**比较纪律：**

1. 选 2–4 家真正可比的同业（业务重合度高），做并表：`公司 | 毛利率 | 净利率 | ROE`（同一报告期口径）。
2. 看**水平**（是否显著高于同业）与**稳定性**（下行年是否掉得更少）。
3. 解释差异：若 ROE 高但主要靠高杠杆而非净利率/周转，护城河叙事要打折。
4. 与 4.1–4.2 交叉：份额领先 + 五力有利 + 利润率/ROE 显著优于同业 → 护城河证据链完整；财务不支撑则下调护城河强度评级。

**输出**：给本公司护城河一个综合判断（宽 / 中等 / 偏窄），并各举不少于 1 条「支持证据」与「反证/隐患」。

### Step 5 — 成长性预测（必做，位于护城河与估值之间）

价值投资分析**必须**显式预测公司未来几年的成长性，不能跳过直接估值。先行业、后公司；营收与净利润都要覆盖。

#### 5.1 行业成长性

至少回答：

- 未来 **3 年（可延至 5 年）** 行业需求大致处于高增 / 中速 / 低速或总量见顶？  
- 量（销量、装机、渗透率）与价（ASP、周期品价格）各自怎么走？  
- 产能周期处于扩张、出清还是均衡？对龙头利润率意味着什么？  
- 依据：历史行业增速、渗透率天花板、政策、资本开支、卖方行业研报共识；注明不确定性。

给出行业口径的：**营业收入增速区间**（或需求量增速 + 价格假设），必要时给乐观 / 中性 / 悲观。

#### 5.2 公司成长性

在行业假设与 Step 4 份额/护城河判断之上，预测本公司：


| 预测项         | 要求                                                  |
| ----------- | --------------------------------------------------- |
| **营业收入**    | 未来至少 **3 个会计年度**的同比增速（或收入绝对额路径）；说明份额升/降假设           |
| **净利润（归母）** | 未来至少 **3 个会计年度**的同比增速（或利润绝对额 / EPS 路径）——**此项为硬性必做** |
| **利润率桥**    | 收入增速如何传到净利：毛利率、费用率、税率、非经常性损益是否归一                    |
| **与一致预期对照** | 并列同花顺/研报一致预期 EPS 或净利增速；说明本预测更高/更低/接近的原因             |


建议输出一张简表，例如：


| 年度  | 行业收入增速(中性) | 公司收入增速 | 公司净利增速 | 关键假设 |
| --- | ---------- | ------ | ------ | ---- |
| T+1 | …          | …      | …      | …    |
| T+2 | …          | …      | …      | …    |
| T+3 | …          | …      | …      | …    |




#### 5.3 纪律（反过拟合）

- 中性情景为主；乐观/悲观各写清触发条件，避免只给一条「保证增速」。  
- 增速须与产能、资本开支、现金流、竞争格局自洽（高增长却无CapEx 要解释）。  
- **禁止**：把最近一季超高增速无调整地外推 3–5 年；**禁止**：只写「成长性良好」而无数字。  
- Step 6 的 Forward PE / PEG 必须引用本步的净利增速（或明确改用一致预期增速并说明）。



### Step 6 — 现阶段估值

必须同时给出：

1. **绝对快照**：PE TTM、PB、（如有）PS；总市值
2. **历史分位**：至少 PE、PB 相对近 3–5 年分位（`baostock_valuation_history`）
3. **前向**：一致预期 EPS 与/或 Step 5 预测 EPS → Forward PE；**PEG 使用 Step 5 的净利润增速假设**（或注明改用一致预期 CAGR）
4. **PB-ROE（必做）**：见下方专节
5. **相对**：2–4 家同业或上下游可比（说明为何可比；同业尽量也算 PB-ROE）

解释「贵/便宜」时，必须说明相对的是**历史、同业还是增长**，避免空泛「估值合理」。估值贵贱应回扣 Step 5：高增长是否已被定价、低增长是否仍给高倍数。

#### PB-ROE 估值（用户惯用，必算）

**定义（按此公式，勿改写）：**


\text{PB-ROE} = \frac{\text{过去 5 年平均 ROE}}{\text{现在的 PB}}


- **含义**：与 PE 类似的一类估值尺子，但用多年平均 ROE 代表可持续股东回报能力，再除以当前 PB，**能平滑短期利润波动**（比单年 PE/单季 ROE 更稳）。  
- **计算口径**：
  1. 取近 5 个完整会计年度（或尽可能接近 5 年）的 ROE，算算术平均；不足 5 年则如实标注年限。
  2. ROE 优先用年报口径：归母净利 / 平均归母权益（期初期末平均）；若只有时点权益，用年末权益并注明。
  3. 「现在的 PB」用当前市价对应的 PB（与报告快照同一时点，通常为腾讯/东财 PB）。
  4. ROE 用小数或百分数须一致：若 ROE=15% 记为 `0.15`，则 PB-ROE = `0.15 / PB`；报告中同时给出百分数表述（如 PB=4、五年均 ROE=20% → PB-ROE = 5%）。
- **解读**：在可比口径下，**PB-ROE 越高通常意味着相对账面盈利能力越便宜**（类盈利收益率视角）。可与 PE 对照：理论上 \mathrm{PB}/\mathrm{ROE} \approx \mathrm{PE}，故 PB-ROE 与 PE 近似互为倒数关系——两者方向应大体一致；若严重背离，检查 ROE 是否被一次性损益扭曲、PB 是否含巨额商誉/金融资产等。  
- **报告中至少写清**：五年各年 ROE、五年平均 ROE、当前 PB、PB-ROE 数值，以及与同业 PB-ROE（若可得）的对比一句。



### Step 7 — 市场看法变化（近 1–2 年）

目的：搞清**定价框架变了没有**——卖方叙事与一致预期如何演变，是否已反映在估值与股价里。不是统计「看多/看空家数」。

#### 7.1 证据材料（强制）

至少使用下列材料中的 **三类**以上，并注明时点（其中第 4 类在近端大跌时**必选**）：

1. 研报：标题主题、评级（买入/增持/中性等）变迁  
2. 一致预期：EPS / 净利增速的上修或下修（如同花顺）  
3. 重要公告窗口：业绩预告/快报、回购进展、定增、重大合同等  
4. **近端定价叙事**：主流财经对股价异动的归因综述；**大客户/供应链公告**（切换供应商、自研替代、多供落地等）

机构持仓披露可作辅证，**不作**价值结论主证据。  
禁止只用卖方研报乐观措辞代替「市场正在交易什么故事」。

#### 7.2 叙事时间轴（强制）

将近 1–2 年划为 **2–4 个叙事阶段**，每段写清大致起止与一句话主题。例如：「缺货扩张」→「利用率与价格」→「回购托底但仍消化估值」。禁止只有印象、没有阶段。

#### 7.3 卖方共识 vs 定价结果（强制分开写）

| 维度 | 看什么 |
|------|--------|
| **卖方** | 研报共识、一致预期方向、关键分歧点（增长、利润率、回购落地、行业周期等） |
| **定价结果** | 同期股价路径、PE/PB 分位或估值中枢是否与卖方叙事同向 |

「基本面好但股价跌 / 基本面平淡但大涨」必须解释：预期差、板块贝塔、还是估值透支后的回归。

#### 7.4 与前文闭环

- 看法变化是否对应 Step 3 的结构变化？还是仅周期噪声？  
- 当前叙事是否已反映在 Step 6 的估值水平里？  
- **预期差（必写）**：卖方/一致预期的未来净利增速 vs Step 5 中性预测——更高、更低还是接近，差在哪、为何。

#### 7.5 输出要求

- 叙事阶段表或条目 + 卖方 vs 定价各一段 + 预期差一句结论  
- 禁止用资金流向、概念热度代替「市场看法」主叙述

### Step 8 — 近期大涨 / 大跌原因调查

目的：用**可核对的价格事实 + 可指名催化**解释波动，服务价值判断；**不做点位预测、不下买卖指令**。

**必须分两层写，禁止混为一谈：**

| 层 | 窗口 | 回答什么 |
|----|------|----------|
| **A. 中期回撤/上涨** | 自阶段高/低点以来（常见 1–6 个月） | 定价框架如何切换（估值压缩、成长→周期等） |
| **B. 近端急跌/急涨** | 近 **5–10 个交易日**（若无显著异动可写「未见急跌」） | **导火索是什么**——必须可指名 |

若只写「高位兑现 / 预期差减弱 / 板块走弱」而无层 B 的事件，**视为 Step 8 不合格**，须补检索后再交付。

#### 8.1 窗口与量化（强制）

- 默认回看 **近 6–12 个月**（可按波动加大到 18 个月，须注明）  
- 写清：阶段**高点**、**低点**、涨幅或回撤幅度（%）、关键 ≥约 4% 的异动日  
- **近端层**：标出最近一次显著下跌/上涨的起止日、幅度、相对同业是否超额  
- 若数据允许：对比异动前与当前的 PE/PB 分位变化

#### 8.2 催化对齐（强制可指名）

对层 A 与层 B 分别对齐催化。每条主因尽量写成：

`日期 | 事件主体（本公司/客户/监管/大宗商品等） | 事件摘要 | 预期差类型 | 公司特有或板块`

预期差类型：超预期 / 符合预期 / 不及预期 / 预期下修 / 叙事切换。

催化来源优先级：异动日前后 0–2 日的**客户或本公司公告** > 主流财经归因综述 > 行业数据/期货异动 > 卖方点评。  
分开写：**上涨催化** vs **下跌/回撤催化**。

#### 8.3 主因排序与公司 vs 板块（强制）

- **主因不超过 3 条**，按重要性排序；近端急跌时，**排序第 1 条优先给导火索事件**（若证据支持）  
- 必须区分：**公司特有** vs **板块/市场贝塔**  
- 尽量对比同期行业指数或 1–2 家同业  
- 若主因涉及客户切换/自研/多供/份额：回写 Step 4「购买者议价 / 替代品 / 变薄路径」，不得只在第八章出现

#### 8.4 纪律

- 禁止以龙虎榜、热点概念、纯技术形态作为**主因**  
- 禁止用抽象标签代替事件：如仅写「情绪降温」「预期差不足」「资金流出」  
- 禁止预测「下一目标价」或保证涨跌  
- 可写：何种信号出现则当前回撤/上涨逻辑弱化或强化（与 Step 9 衔接）

### Step 9 — 综合结论与跟踪清单

目的：把前文收成**可检验的研究结论**，不是另起炉灶写观点文章。

#### 9.1 一句话匹配判断（强制，非买卖指令）

在摘要之前，用**一句**概括「质量 × 成长 × 估值」的匹配状态。  
示例方向（可改写，勿变成荐股）：「质地扎实、中性增速可兑现，估值处历史偏低，但行业定价承压。」

禁止写成「建议买入/卖出」或目标价。

#### 9.2 投资摘要与对照（强制回扣前文）

- 摘要 ≤4 条，须点到主要矛盾  
- 乐观理由 / 谨慎理由对照  
- **必须点名回扣**：护城河结论（Step 4）、成长中性假设（Step 5）、估值尺子含 PB-ROE（Step 6）、主涨跌逻辑（Step 8）

#### 9.3 中性情景前提与关键风险

- 写清 Step 5 中性情景成立的 **2–4 条前提**  
- 列 **2–4 条关键风险**（最好可被后续数据证伪）

#### 9.4 可证伪跟踪表（加厚）

表格列：`信号 | 看多确认 | 看空确认`。至少覆盖下列类别各 ≥1 行（无数据则写监控方式）：

| 类别 | 示例信号 |
|------|----------|
| 基本面 | 收入/净利增速、毛利率/净利率、经营现金流或 FCF |
| 竞争 | 份额、产品价格/ASP、大客户多供变化 |
| 估值 | PE/PB 分位、PB-ROE 相对同业 |
| 催化 | 回购是否落地、重要产能/订单、监管或行业政策 |

其中须含：收入/净利是否达到 Step 5 中性假设。

#### 9.5 文末

- 免责声明：仅供研究整理，不构成投资建议  
- 可一句重申：本框架不适配题材股、小市值股、亏损股

### 可视化纪律（总览 + 合订报告，硬规则）

总览与单独投研报告的读者是「扫读」而不是「精读分册」。排版优先顺序：**图 → 表 → 短结论句**。长段落只用来解释表/图看不出来的因果关系。

| 要求 | 说明 |
|------|------|
| **能成表则表** | 多期财务、同业对比、份额/集中度、成长预测、估值尺子、催化事件、跟踪清单，一律用 Markdown 表，禁止改写成散文罗列 |
| **能出图则图** | 合订报告至少 **3 张图**，总览至少 **1 张图**。优先：营收/净利柱状或折线、份额饼图或条形、估值/股价路径、叙事时间线。默认用 **Mermaid**（只用 `xychart-beta` 和 `flowchart`；**不要用 `timeline` / `pie`**），保证纯 Markdown 可渲染；已有 Canvas 的可在总览加一句链接，**不能替代**文内图 |
| **Mermaid 须能渲染** | 预览报 `Syntax Error` 等于没出图。Cursor 预览里 **不要用 `timeline`、不要用 `pie`**。时间线用 `flowchart LR`（`A["2024 营收走平"]`）；份额/结构用 `xychart-beta` 柱状，不要画饼图。其余：① `title` 与轴标签加双引号；② **xychart 禁止负数**；③ 轴标签禁止未加引号的 `25-01` |
| **每张表/图一句读法** | 表或图下方用 1 句说明「看出什么」，不要把表里的数字再抄成一段 |
| **禁止** | 总览九章各写一大段文字、合订报告整章无表无图、用「大约/较好」代替已有精确数、为凑汉字把表拆回散文 |

分册仍以证据厚度为准，但也优先表；可视化纪律的检查对象是 **`00-总览` 与合订报告**。

## 反例（禁止）

- **只交分册、总览只有目录没有各章浓缩，或缺省单独投研报告**  
- **总览或合订报告以大段文字平铺，能成表的数据仍写成散文，或合订报告通篇无图**  
- **为加厚分册而臆造财务、市占、新闻或催化**  
- **无目录，或总览目录展开到分册内的 `###` 二级小节**  
- 竞争格局只列对手名字、不写集中度与市占；护城河只写形容词、不做五力与利润率/ROE 同业比较
- 基本面只贴财报表格、无生意模式与 FCF/杜邦解读；重大变化无时间线、不区分周期与结构
- **用装机/销量/产能结构代替分部收入与利润表**（例如只写煤电装机 57%，不写电力销售收入、煤机/水电/风光利润总额）  
- 只给目标价/买卖点，不给生意与估值过程  
- 市场看法只写「情绪降温」无阶段轴与研报/一致预期证据；涨跌归因主因靠龙虎榜或概念
- **近端大跌归因只有「预期差减弱/高位兑现/板块β」，却漏掉异动日前后已公开的客户切换、自研替代、回购零实施、监管等可指名事件**
- **因用户说「财务可复用」而跳过新闻与 Web「下跌原因」检索，导致第八章过时**
- 综合结论另起炉灶、不回扣护城河/成长/估值/涨跌；无跟踪表或跟踪表不可证伪
- 跳过成长性预测直接谈「低估/高估」  
- 把一季增速外推成永续高增长而不讨论竞争与资本开支  
- 对亏损题材股套用本模板并得出「低估」结论
